# project_rules.md

## Project-Level Rules

- Apply this file in addition to core and mode rules.

## React + Tailwind UI Scaffold

- Implement these scaffold layout primitives: `PageLayout`, `PageHeader`, `Section`, `FormContainer`, `Stack`.
- Build scaffold primitives with React + Tailwind.
- Place scaffold components in `/components/ui`.
- Use max width `1200px`, centered layout, and page padding for `PageLayout`.
- Use max width `500px` for `FormContainer`.
- Keep scaffold components simple; avoid variants, complex props, and non-layout behavior.
